# SATL

Простой и красочный клиент для Home Assistant с режимом киоска.

Один код — Android и iPhone. Сделан так, чтобы новый пользователь разобрался
за минуту: адрес сервера, логин, пароль — и всё.

## Возможности

- Список серверов с цветными карточками, статусом и задержкой.
- Добавление сервера в три поля (адрес, логин, пароль) или по долгоживущему токену.
- Пароль не сохраняется — приложение хранит только выданный сервером токен.
- Переключение между серверами в один тап.
- Обзор: версия, отклик, плитки устройств (свет, розетки, климат, датчики).
  Управление светом и розетками прямо из обзора.
- Панель: полноценный интерфейс Home Assistant внутри приложения.
- Режим киоска: полный экран без панелей, выход по PIN
  (долгое нажатие в левом верхнем углу).

## Установка (Android)

1. Скопируйте `SATL.apk` на телефон.
2. Разрешите установку из неизвестных источников, если телефон спросит.
3. Откройте приложение, нажмите «Добавить сервер».
4. Введите адрес (`192.168.1.125:8123` дома или внешний адрес),
   логин и пароль от Home Assistant.

## Режим киоска

Долгое нажатие на карточку сервера → «Режим киоска и PIN».

- «Открывать на весь экран» — убирает панели и кнопки, остаётся только панель
  Home Assistant, как табло на стене.
- «Запускать при старте» — приложение при открытии сразу заходит в киоск
  этого сервера, минуя список.
- PIN по умолчанию `0000`, его можно заменить своим.

Выход: долгое нажатие в левом верхнем углу → PIN.

## Сборка из исходников

Нужны Flutter 3.47+, JDK 17, Android SDK.

```bash
flutter pub get
flutter build apk --release
```

Готовый файл: `build/app/outputs/flutter-apk/app-release.apk`.

Для iPhone (только на macOS с Xcode):

```bash
flutter build ipa --release
```

## Публикация в магазинах

- Google Play: нужен аккаунт разработчика (25 $ разово), подписанный
  release-ключ (см. `STORE.md`), политика конфиденциальности и скриншоты.
- App Store: нужен аккаунт Apple Developer (99 $ в год), Mac с Xcode,
  TestFlight для тестирования.

Подробная инструкция — в `STORE.md`.

## Ограничения текущей версии

- Токены хранятся в локальных настройках приложения (не в системном хранилище
  ключей). Для публикации в сторах это стоит заменить на flutter_secure_storage.
- Двухфакторный вход Home Assistant не поддерживается в форме логина —
  используйте долгоживущий токен.
- Панель открывается во встроенном браузере, поэтому некоторые нестандартные
  карточки могут вести себя иначе, чем в браузере.
